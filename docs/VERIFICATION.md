# 验证记录

日期：2026-10-12。插件：0.4.3。宿主：DeepSeek Harness 0.2.0-rc.2。

## 自动验证

`npm run check` 包含构建、15 项逻辑测试和隔离 DSH web profile 中的页面测试。

- 模型目录的精确 ID、协议及托管端点匹配，Claude 完全关闭能力和默认值校验。
- 已有模型自动补齐、输入完整 ID 自动匹配、同 ID 编辑保留定制、未知模型不猜测匹配。
- 多行编辑、容量校验、改名、增删模型，以及原生保存、取消、重置。
- 标签内的“设为默认”按钮、默认标签、折叠和重新打开后的状态。
- DeepSeek 原生和 Codex 两种选择器的即时切换及插件禁用恢复。
- Codex 滑杆的键盘和鼠标操作，按模型显示实际档位，最高档位粒子动画，排除 Ultra。
- 标准圆角面板和圆形滑块；面板展开、菜单切换、高度过渡及滑杆吸附动画。按布局尺寸测量高度，展开过程中底边保持固定；档位与模型名称共用悬停背景。
- 两个界面选项显示在通用设置中，沿用 DSH 行式布局和原生开关；无独立 Tab 和额外外框。
- 设置持久化、页面重载、编辑器 UI 独立开关；切换样式或关闭 UI 不写入模型配置。
- Escape 返回上一级、关闭后恢复焦点、窄窗口布局、深色主题、减少动态效果。
- 大模型目录搜索、360px 最大菜单高度、固定标题和搜索框、隐藏滚动条且保留列表滚动、所有模型的渠道说明，以及无思考能力模型的选择。
- 测试过程中没有页面异常。

页面测试使用本地模拟 Anthropic 服务。通过 DSH 原生会话切换路径验证请求：Codex 的 xhigh、low 和拖动选择的 max，均发送对应的 `output_config.effort`；选择 off 时发送 `thinking.type = "disabled"`，不附带 output_config。再次选择 high 后恢复 adaptive thinking。

## 桌面验证

在已安装的 macOS DeepSeek Harness 中升级并重新启动插件，检查设置入口及 Codex 选择器的实际显示。桌面版原有模型、服务商和自定义档位在升级过程中保留。

## 兼容范围

模型目录包含 83 个明确 ID、42 条协议规则，并附官方来源。未逐一请求各厂商付费接口。

选择器使用官方 `conversation.input.model` 和 `settings.general.item` 插槽，沿用宿主的 ModelDirectory 和会话切换接口。行内编辑器的草稿桥接及 PiAiAdapter 默认值适配依赖 DSH 0.2.0-rc.2；升级宿主后需要复核这些接口。

内置 DeepSeek 适配器提供 `off / low / high / max`，默认 `high`；关闭 thinking 的渠道仅提供 `off`。其模型 schema 不含自定义档位字段，行内编辑器保持仅适配 Pi AI 自定义渠道。此结论核对了已安装宿主的模型 schema、元数据和请求构造代码。

界面偏好保存在当前客户端的 localStorage；模型档位通过原生服务商编辑器保存。禁用插件会恢复宿主选择器，模型扩展字段仍保留。
