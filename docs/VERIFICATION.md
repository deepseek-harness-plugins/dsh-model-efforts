# 验证记录

日期：2026-10-12。插件：0.5.0。宿主：DeepSeek Harness 0.2.0-rc.2。

## 自动验证

构建和 14 项逻辑测试通过，独立安装的隔离 DSH web profile 页面测试通过。

- 精确模型 ID、协议与托管端点匹配，官方来源与档位范围校验。
- 已有模型自动补齐、输入完整 ID 自动匹配、同 ID 编辑保留定制、未知模型手动配置。
- 多行编辑、容量校验、改名、增删模型，以及原生保存、取消、重置。
- 标签内的“设为默认”按钮与默认标签，折叠、重新打开和页面重载后的状态。
- 默认值同时作用于模型目录和实际请求，显式档位优先，已准备请求保留其默认值快照。
- `off` 请求发送 `thinking.type = "disabled"`，切回 `high` 恢复 adaptive thinking。
- 通用设置只包含档位编辑器开关；没有 Codex 样式设置和自定义聊天选择器。
- 关闭编辑器 UI 不改写模型配置，插件禁用恢复宿主默认值行为。
- 新偏好优先、旧版开关继承与两个插件偏好存储互不覆盖。
- 测试过程中没有页面异常。

页面请求使用本地模拟 Anthropic 服务；未逐一调用各厂商付费接口。

## 拆分兼容性

与 DSH Codex Picker 0.1.0 同时安装的联合页面测试通过。编辑器保存的模型档位与默认值会出现在独立选择器中，选择 `low / xhigh / max / off` 后请求参数一致。

单独禁用编辑器时 Codex 选择器继续可用；两个插件禁用后恢复原生选择器。界面偏好各自保存，旧版的 `effortEditor` 开关会继续沿用。

## 兼容范围

模型目录收录 83 个明确 ID、42 条协议规则，附官方文档来源。行内编辑器的草稿桥接与 PiAiAdapter 默认值适配基于 DSH 0.2.0-rc.2；升级宿主后需复核这些接口。

内置 DeepSeek 适配器提供 `off / low / high / max`，默认 `high`；其模型 schema 不含自定义档位字段，行内编辑器适配 Pi AI 自定义渠道。

模型档位通过原生服务商编辑器保存。界面开关保存在客户端 localStorage；禁用插件仍保留模型扩展字段。
