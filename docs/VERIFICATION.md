# 验证记录

日期：2026-10-12。插件：0.3.0。宿主：本机安装的 DeepSeek Harness 0.2.0-rc.2。功能验证运行在隔离的 web profile，使用系统 Chrome。

## 已验证

- 构建成功，客户端约 17 KB，服务端约 4 KB，使用 DSH 共享的 React。
- 10 项逻辑测试通过，包括目录、协议和托管端点范围、原字段保留、重置、默认值校验、模型间独立默认值、显式选择优先、旧快照一致性、实例方法恢复和非法默认值拒绝。
- 控件位于每个展开模型的容量设置下方、输入类型上方。
- 界面只显示思考强度、档位标签、添加档位、自动匹配、重置；没有独立保存和取消按钮或说明区。
- 档位标签和添加列表直接显示 `off`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`，不翻译成中文。
- Opus 5.5 匹配 low / medium / high / xhigh / max；Sonnet 4.6 不提供 xhigh。
- 标签增删、重置以及折叠后重新展开均正常。
- 只修改思考档位即可通过原生“保存”写入并重新打开读回。
- 原生“取消”同时丢弃容量和档位修改，配置文件不变。
- 容量修改、模型改名、新模型配置和删除前面的模型可以一起保存；重新打开后，各模型档位仍正确对应。
- 容量无效时，原生校验禁止保存，档位草稿不写入配置。
- 未知模型的自动匹配禁用，手动添加可用。
- 点击标签设置默认值，小圆点标记；折叠、保存读回、重置、取消都包含默认值。
- 仅修改默认值也能通过原生保存持久化，模型目录读回新的默认值。
- Opus 默认 medium、手工模型默认 off、新添加的 Sonnet 默认 xhigh，改名和删除其他模型后仍各自对应。
- 设置明确默认值后，聊天菜单显示 Low、Medium、High、Xhigh、Max，没有 Default，并正确默认选中 Medium。
- 默认 Medium 和显式选择 Max 的真实聊天请求均发往本地模拟 Anthropic 服务，分别包含 `output_config.effort = "medium"` / `"max"`，以及 `thinking.type = "adaptive"`。
- 手工模型单独显示 Off、High，默认 Off 的请求包含 `thinking.type = "disabled"`，没有 output_config。
- 禁用插件后恢复原生菜单的 Default 选项。
- 测试过程中没有页面异常。

## 验证边界

目录的 83 个明确 ID（包含官方别名和日期版本）、40 条协议规则均附官方来源；没有逐一请求所有厂商的付费接口。GLM、Kimi 规则限定 QwenCloud 托管端点。

未请求 RightCode 或其他付费模型。0.3.0 已安装并启用到日常 desktop profile，安装后的客户端和服务端文件与构建产物一致。此前 0.2.0 的原生 macOS 设置窗口控件加载已确认；桌面自动点击不稳定，0.3.0 完整操作流程在隔离 web profile 验证。revision 冲突处理沿用原生编辑器，本轮未制造远程冲突进行验证。

页面挂载采用官方 footer 插槽；单模型位置、草稿回调和 PiAiAdapter 的局部默认值适配依赖 DSH 0.2.0-rc.2，宿主升级需复核。默认值是模型扩展字段，禁用插件后字段保留，但请求采用原生行为。
