# 验证记录

日期：2026-10-12。插件：0.3.7。宿主：DeepSeek Harness 0.2.0-rc.2。完整功能验证运行在隔离的 web profile，使用系统 Chrome。

## 已验证

- 构建成功，客户端约 19.1 KB，服务端约 4 KB，使用 DSH 共享的 React。
- 11 项逻辑测试通过，包括目录、Claude 完全关闭能力、协议和托管端点范围、原字段保留、重置、默认值校验、模型间独立默认值、显式选择优先、旧快照一致性、实例方法恢复和非法默认值拒绝。
- 控件位于每个展开模型的容量设置下方、输入类型上方。
- 界面包含思考强度、档位标签、标签内的“设为默认”文字按钮、添加档位、自动匹配、重置，使用原生保存和取消。
- 档位标签和添加列表直接显示 `off`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`，不翻译成中文。
- Opus 5.5 匹配 low / medium / high / xhigh / max，不提供 off；Sonnet 4.6 提供 off / low / medium / high / max，不提供 xhigh。
- 标签增删、重置以及折叠后重新展开均正常。
- 只修改思考档位即可通过原生“保存”写入并重新打开读回。
- 原生“取消”同时丢弃容量和档位修改，配置文件不变。
- 容量修改、模型改名、新模型配置和删除前面的模型可以一起保存；重新打开后，各模型档位仍正确对应。
- 容量无效时，原生校验禁止保存，档位草稿不写入配置。
- 未知模型的自动匹配禁用，手动添加可用。
- 已有 Haiku 5.5 不修改 ID、不点击自动匹配，打开编辑器即自动填入 off / low / medium / high / xhigh / max，默认 high。
- 多个已有模型同时待匹配时，折叠行依次更新，并可原生保存、重新打开读回；未知模型保持未配置。
- 初次自动补齐后，重置再折叠展开仍保持原始空状态；取消不写入配置。重新打开编辑器会再次补齐未配置模型。
- 明确删除全部档位并保存后，重新打开不会自动补回；已有自定义档位和默认值保留。
- 输入完整模型 ID 后，无需点击按钮或离开输入框，即自动匹配档位。快速输入 Sonnet 5.5 不会按 Sonnet 5 的前缀误配出 off。
- 修改模型显示名称、重新输入相同 ID，以及折叠后展开均保留手动档位和默认值；重置清空新模型的配置后，不会自动补回。
- 未收录的模型 ID 不会被猜测匹配；“自动匹配”按钮仍能恢复已收录模型的目录预设。
- 新增模型在选项折叠时输入 ID，立即点击原生保存，自动匹配的档位和默认值能够写入并重新打开读回。
- ID 修改后的待匹配状态可以原生取消，延迟匹配不会写入配置；打开编辑器的自动补齐同样只修改草稿。
- 非默认档位的标签内显示“设为默认”文字按钮，单击直接修改编辑草稿的默认值。当前默认档位不显示该按钮。
- 默认档位显示可见的 `default` 标签；切换后，新默认档位隐藏按钮并显示标签，原默认档位恢复按钮，折叠、保存读回和重置后状态正确。
- 仅修改默认值也能通过原生保存持久化，模型目录读回新的默认值。
- Opus 默认 medium、手工模型默认 off、新添加的 Sonnet 默认 xhigh，改名和删除其他模型后仍各自对应。
- 设置明确默认值后，聊天菜单显示 Low、Medium、High、Xhigh、Max，没有 Default，并正确默认选中 Medium。
- 默认 Medium 和显式选择 Max 的真实聊天请求均发往本地模拟 Anthropic 服务，分别包含 `output_config.effort = "medium"` / `"max"`，以及 `thinking.type = "adaptive"`。
- 手工模型单独显示 Off、High，默认 Off 的请求包含 `thinking.type = "disabled"`，没有 output_config。
- 官方目录中的 Opus 5 自动匹配 Off、Low、Medium、High、Xhigh、Max。设默认 Xhigh 后，聊天显式选择 Off 的请求仍只发送 `thinking.type = "disabled"`，没有 output_config；再选择 High 时恢复 adaptive 和 effort = high。
- Claude 关闭能力覆盖 14 个已收录 ID：7 个提供 off，7 个不提供。Sonnet 5.5 的 between_tools 不标为完全关闭。
- 禁用插件后恢复原生菜单的 Default 选项。
- 测试过程中没有页面异常。
- 桌面版升级并重新启动后，已有 Haiku 5.5 打开编辑器即显示六个档位和 high 默认标签。通过原生保存读回六个档位和默认值；服务商设置、模型 ID、容量及原有自定义档位一致。
